# Personal academic homepage

This is a Quarto website intended for Cloudflare Pages.

## Local preview

Install Quarto, then run:

```sh
quarto preview
```

## Cloudflare Pages build settings

- Build command: `quarto render`
- Build output directory: `_site`
- Root directory: `/`

Replace the placeholder text in the `.qmd` files, update the site URL in `_quarto.yml`, and add any images or PDF files under `assets/`.
